# No affiliate links, referrals, or paid placement

Rankings are driven solely by the user's benefit and the site states this openly, alongside a "not financial advice" disclaimer. Monetization was rejected because a trust breach is effectively irreversible for a recommendation product, and affiliate programs would add FTC disclosure obligations. Costs are controlled by quotas and model routing instead.

## Addendum (2026-10-01): referral facts

Saying that a referral helps is not the same as using one. Some cards give applicants more
through a referral from someone who already has the card: Discover it Student adds $100, and
Amex referral links more often show the full "up to" offer. The catalog records these as
reviewed facts (`catalog/seed/referrals.yaml`), each with its source, confidence and date. The
site and the Advisor tell people the benefit exists, so they can ask a friend. We still never
give, collect, rank by, or earn from referral links, and the bonus is not counted in rankings,
since it depends on knowing a cardholder.
